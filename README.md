# @coderwyd/prettier-config

Prettier config.

## Install

```bash
npm i -D @coderwyd/prettier-config
```

## Features

- 2 spaces
- No semicolons
- Single quotes
- Trailing commas
- Ignore common files (`dist`, `pnpm-lock.yaml`...)
- OXC plugin
- Tailwind CSS plugin (if `tailwindcss` is installed)
